# Resolução nº 1314/1974

RESOLUÇÃO Nº 1.314, de 10 de dezembro de 1974

**Art. 1º** Fica transferido da Unidade 41.01.00, Assembléia Legislativa, o recurso das rubricas abaixo:

| Elemento | 3.1.2 |  |
| --- | --- | --- |
| Subelemento | 12.00 | 5.000,00 |
| Elemento | 3.1.3 |  |
| Subelemento | 06.00 | 5.000,00 |
| Subelemento | 11.00 | 30.000,00 |

| Elemento | 3.1.3 |  |
| Subelemento | 04.00 | 5.000,00 |
| Subelemento | 07.00 | 3.000,00 |
| Subelemento | 08.00 | 20.000,00 |
| Subelemento | 09.00 | 3.000,00 |
| Subelemento | 10.00 | 3.000,00 |
| Subelemento | 13.00 | 1.000,00 |

**Art. 3º** Esta Resolução entra em vigor na data de sua publicação revogadas as disposições em contrário.
