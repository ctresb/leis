# Resolução nº 4742/2017

RESOLUÇÃO Nº 4.742, DE 06 DE JUNHO DE 2017.

Altera a Resolução nº 2.890, de 23 de dezembro de 2010, que dispõe sobre a estrutura organizacional dos serviços administrativos da Secretaria da Assembleia Legislativa e sobre o Plano de Cargos e Carreiras dos seus respectivos servidores.

**A MESA DA ASSEMBLEIA LEGISLATIVA DO ESTADO DO ESPÍRITO SANTO,** usando das atribuições que lhe são conferidas pelo artigo 17, inciso XXVI do Regimento Interno, aprovado pela Resolução nº 2.700, de 15 de julho de 2009, promulga a seguinte Resolução:

**Art. 1º** Fica alterado o item 02 do Anexo IV - Nível de Direção e Assessoramento Estratégico - constante da Resolução nº 2.890, de 23 de dezembro de 2010, que passa a ter a seguinte redação:

**“Anexo IV**

| **NÍVEL DE DIREÇÃO E ASSESSORAMENTO ESTRATÉGICO** |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
| (...) |  |  |  |  |  |  |
| 02 | Procurador Geral | Procuradoria Geral | PG | Advogado com inscrição regular na Ordem dos Advogados do Brasil - OAB | 01 | MESA |
| (...).” (NR) |  |  |  |  |  |  |

**Art. 2º** Os itens 2.2 e 2.3 do Anexo V da Resolução nº 2.890, de 2010, passam a vigorar com a seguinte redação:

“2. ..........................................................................................................

..........................................................................................................

2.2. Escolaridade: Curso superior completo em Direito

**2.3. Qualificação:** Advogado com inscrição regular na Ordem dos Advogados do Brasil - OAB

................................................................................................” (NR)

**Art. 3º Esta Resolução entra em vigor na data de sua publicação.**

Palácio Domingos Martins, em Vitória, 06 de junho de 2017.
