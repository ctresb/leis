# Decreto do Executivo n° 22.415

4020.doc - -00**DECRETO Nº 22.415, DE 03 DE JULHO DE 2000.**

Abre ao Orçamento Fiscal do Estado, crédito suplementar no valor de R$ 150.000,00, em favor da Escola de Contas Públicas Professor Barreto Guimarães.

O GOVERNADOR DO ESTADO, no uso das atribuições que lhe são conferidas pelo inciso IV do artigo 37 da Constituição Estadual, tendo em vista o disposto na alínea “ a” , do inciso IV, do artigo 10, da Lei nº 11.724, de 23 de dezembro de 1999, e considerando a necessidade de reforçar dotação orçamentária insuficiente para cobrir despesas com a realização de quarenta cursos da Escola de Contas Públicas Professor Barreto Guimarães, não implicando acréscimo ao Orçamento vigente, uma vez que os recursos serão deduzidos de dotação disponível,

DECRETA:

**Art. 1º** Fica aberto ao Orçamento Fiscal do Estado para o presente exercício, em favor da Escola de Contas Públicas Professor Barreto Guimarães, crédito suplementar no valor de R$ 150.000,00 (cento e cinquenta mil reais), destinado ao reforço da dotação orçamentária abaixo discriminada:

RECURSOS DO TESOURO EM R$ 1,00

| 82000 | - | TRIBUNAL DE CONTAS - ENTIDADES SUPERVISIONADAS |  |
| --- | --- | --- | --- |
| 82010 | - | Escola de Contas Públicas Professor Barreto Guimarães |  |
| 82010.0112802024.126 | - | Aperfeiçoamento profissional e reequipamento técnico - ECPBG | **150.000** |
| 3.4.90 - FNT 01 | - | Outras Despesas Correntes | 150.000 |
|  |  |  | ------------ |
|  |  | **TOTAL** | **150.000** |
|  |  |  | ======= |

**Art. 2º** Os recursos necessários ao atendimento da despesa de que trata o artigo anterior são os provenientes da anulação, em igual importância, da dotação orçamentária a seguir discriminada:

RECURSOS DO TESOURO EM R$ 1,00

| --- | --- | --- | --- |
| 82010 | - | Escola de Contas Públicas Professor Barreto Guimarães |  |
| 82010.0112802023.047 | - | Estruturação física da ECPBG | **150.000** |
| 4.5.90 - FNT 04 | - | Investimentos | 150.000 |
|  |  |  | ------------ |
|  |  | **TOTAL** | **150.000** |
|  |  |  | ======= |

**Art. 3º** Este Decreto entra em vigor na data de sua publicação.

**Art. 4º** Revogam-se as disposições em contrário.

Palácio do Campo das Princesas, em 03 de julho de 2000.
