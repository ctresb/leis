# Decreto do Executivo n° 23.207

**DECRETO Nº 23 207, DE 19 DE ABRIL DE 2001.**

Abre ao Orçamento Fiscal do Estado crédito suplementar no valor de R$150.000,00, em favor da Secretaria de Planejamento e Desenvolvimento Social.

O GOVERNADOR DO ESTADO, no uso das atribuições que lhe são conferidas pelo inciso IV do artigo 37 da Constituição Estadual, tendo em vista o disposto na alínea “a”, do inciso IV, do artigo 10, da Lei nº 11.898, de 19 de dezembro de 2000, e considerando a necessidade de reforçar dotação orçamentária insuficiente para cobrir despesas com ressarcimento de pessoal à disposição da SEPLANDES, não implicando acréscimo ao Orçamento vigente, uma vez que os recursos serão deduzidos de dotação disponível,

DECRETA:

**Art. 1º** Fica aberto ao Orçamento Fiscal do Estado para o presente exercício, em favor da SECRETARIA DE PLANEJAMENTO E DESENVOLVIMENTO SOCIAL, crédito suplementar no valor de R$ 150.000,00 (cento e cinquenta mil reais), destinado ao reforço da dotação orçamentária a seguir discriminada:

RECURSOS DO TESOURO EM R$ 1,00

| 30000 | - | SECRETARIA DE PLANEJAMENTO E DESENVOLVIMENTO SOCIAL |  |
| --- | --- | --- | --- |
| 30010 | - | Secretaria de Planejamento e Desenvolvimento Social - Administração Direta |  |
| 30010.2884630259.267 | - | Ressarcimento de despesa com pessoal à disposição da SEPLANDES | **150.000** |
| 3.4.90 - FNT 01 | - | Outras Despesas Correntes | 150.000 |
|  |  |  | ----------- |
|  |  | **TOTAL** | **150.000** |
|  |  |  | ====== |

**Art. 2º** Os recursos necessários ao atendimento da despesa de que trata o artigo anterior são os provenientes da anulação, em igual importância, da dotação a seguir discriminada:

| 30010.1133130201.274 | - | Ampliação das agencias do trabalho | **150.000** |

|  |  |  | ----------- |
|  |  | **TOTAL** | **150.000** |
|  |  |  | ====== |

**Art. 3º** Este Decreto entra em vigor na data de sua publicação.

**Art. 4º** Revogam-se as disposições em contrário.

Palácio do Campo das Princesas, em 19 de abril de 2001.
