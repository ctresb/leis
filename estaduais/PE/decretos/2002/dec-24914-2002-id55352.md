# Decreto do Executivo n° 24.914

**DECRETO Nº 24.914, DE 14 DENOVEMBRO DE 2002.**

Abre ao Orçamento Fiscal do Estado, crédito suplementar no valor de R$ 230.000,00, em favor do Tribunal de Justiça.

O GOVERNADOR DO ESTADO, no uso das atribuições que lhe são conferidas pelo inciso IV do artigo 37 da Constituição Estadual, tendo em vista o disposto no inciso IV, do artigo 10, da Lei nº 12.147, de 26 de dezembro de 2001, e considerando a necessidade de reforçar dotação orçamentária insuficiente para fazer face a despesas com pessoal do Tribunal de Justiça, não implicando acréscimo ao Orçamento vigente, uma vez que os recursos serão deduzidos de dotação disponível,

DECRETA:

**Art. 1º** Fica aberto ao Orçamento Fiscal do Estado para o presente exercício, em favor do TRIBUNAL DE JUSTIÇA, crédito suplementar no valor de R$ 230.000,00 (duzentos e trinta mil reais), destinado ao reforço da dotação orçamentária a seguir discriminada:

RECURSOS DO TESOURO EM R$ 1,00

| 07000 | - | TRIBUNAL DE JUSTIÇA |  |
| --- | --- | --- | --- |
| 07010 | - | Tribunal de Justiça - Administração Direta |  |
| 07010.0212207098.016 | - | Gestão das atividades de apoio do Tribunal de Justiça | **230.000** |
| 3.1.90 - FNT 0101 | - | Pessoal e Encargos Sociais | 230.000 |
|  |  |  | ----------- |
|  |  | **TOTAL** | **230.000** |
|  |  |  | ======= |

**Art. 2º** Os recursos necessários ao atendimento da despesa de que trata o artigo anterior são os provenientes da anulação, em igual importância, da dotação a seguir discriminada:

| 29030.2884629109.100 | - | Encargos com restituições e indenizações | **230.000** |
| 3.1.90 - FNT 0101 | - | Pessoal e Encargos Sociais | 230.000 |
|  |  |  | ------------ |
|  |  | **TOTAL** | **230.000** |
|  |  |  | ======= |

**Art. 3º** Este Decreto entra em vigor na data de sua publicação.

**Art. 4º** Revogam-se as disposições em contrário.

Palácio do Campo das Princesas, em 14 de novembro de 2002.
