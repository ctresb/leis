# Decreto do Executivo n° 25.443

**DECRETO Nº 25.443, DE 08 DE MAIO 2003.**

Abre ao Orçamento Fiscal do Estado, relativo ao exercício de 2003, crédito suplementar no valor de R$ 500.000,00, em favor da Secretaria de Planejamento

O GOVERNADOR DO ESTADO, no uso das atribuições que lhe são conferidas pelo inciso IV do artigo 37 da Constituição Estadual, tendo em vista o disposto no inciso IV, do artigo 10, da Lei nº 12.298, de 17 de dezembro de 2002 e na Lei nº 12.345, de 24 de março de 2003, e considerando a necessidade de reforçar dotação orçamentária insuficiente para cobrir despesas relativas ao PROMATA, não implicando acréscimo ao Orçamento vigente, uma vez que os recursos serão deduzidos de dotação disponível,

DECRETA :

**Art. 1º** Fica aberto ao Orçamento Fiscal do Estado, relativo ao exercício de 2003, em favor da SECRETARIA DE PLANEJAMENTO, crédito suplementar no valor de R$ 500.000,00 (quinhentos mil reais), destinado ao reforço da dotação orçamentária a seguir discriminada:

RECURSOS DO TESOURO EM R$ 1,00

| 30000 | - | SECRETARIA DE PLANEJAMENTO |  |
| --- | --- | --- | --- |
| 30010 | - | Secretaria de Planejamento - Administração Direta |  |
| 30010.0412190022.245 | - | Coordenação, supervisão, monitoramento e apoio operacional ao PROMATA | **500.000** |
| 3.3.90 - FNT 0101 | - | Outras Despesas Correntes | 500.000 |
|  |  |  | ----------- |
|  |  | **TOTAL** | **500.000** |
|  |  |  | ======= |

**Art. 2º** Os recursos necessários ao atendimento da despesa de que trata o artigo anterior são os provenientes da anulação, em igual importância, da dotação a seguir discriminada:

RECURSOS DO TESOURO EM R$ 1,00

| 30000 | - | SECRETARIA DE PLANEJAMENTO |  |
| --- | --- | --- | --- |
| 30010 | - | Secretaria de Planejamento - Administração Direta |  |
| 30010.0412190021.239 | - | Execução de ações do PROMATA pela SEPLANDES | **500.000** |
| 4.4.90 - FNT 0101 | - | Investimentos | 500.000 |
|  |  |  | ----------- |
|  |  | **TOTAL** | **500.000** |
|  |  |  | ======= |

**Art. 3º** Este Decreto entra em vigor na data de sua publicação.

**Art. 4º** Revogam-se as disposições em contrário.

Palácio do Campo das Princesas, em 08 de maio de 2003.

JARBAS DE ANDRADE VASCONCELOS
