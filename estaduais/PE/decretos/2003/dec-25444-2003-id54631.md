# Decreto do Executivo n° 25.444

**DECRETO Nº 25.444, DE 08 DE MAIO 2003.**

Abre ao Orçamento Fiscal do Estado, relativo ao exercício de 2003, crédito suplementar no valor de R$ 13.500,00, em favor da Governadoria do Estado.

O GOVERNADOR DO ESTADO, no uso das atribuições que lhe são conferidas pelo inciso IV do artigo 37 da Constituição Estadual, tendo em vista o disposto no inciso IV, do artigo 10, da Lei nº 12.298, de 17 de dezembro de 2002 e na Lei nº 12.345, de 24 de março de 2003, e considerando a necessidade de reforçar dotação orçamentária insuficiente para cobrir despesas com a elaboração do Projeto das instalações elétricas do prédio sede do Gabinete do Vice-Governador, não implicando acréscimo ao Orçamento vigente, uma vez que os recursos serão deduzidos de dotação disponível,

DECRETA :

**Art. 1º** Fica aberto ao Orçamento Fiscal do Estado, relativo ao exercício de 2003, em favor da GOVERNADORIA DO ESTADO, crédito suplementar no valor de R$ 13.500,00 (treze mil e quinhentos reais), destinado ao reforço da dotação orçamentária a seguir discriminada:

RECURSOS DO TESOURO EM R$ 1,00

| 11000 | - | GOVERNADORIA DO ESTADO |  |
| --- | --- | --- | --- |
| 11040 | - | Casa Militar - Administração Direta |  |
| 11040.0612236047.025 | - | Construção e melhoria das instalações da Casa Militar | **13.500** |
| 4.4.90 - FNT 0101 | - | Investimentos | 13.500 |
|  |  |  | --------- |
|  |  | **TOTAL** | **13.500** |

**Art. 2º** Os recursos necessários ao atendimento da despesa de que trata o artigo anterior são os provenientes da anulação, em igual importância, da dotação a seguir discriminada:

| 3.3.90 - FNT 0101 | - | Outras Despesas Correntes | 13.500 |
|  |  |  | --------- |
|  |  | **TOTAL** | **13.500** |
|  |  |  | ====== |

**Art. 3º** Este Decreto entra em vigor na data de sua publicação.

**Art. 4º** Revogam-se as disposições em contrário.

Palácio do Campo das Princesas, em 08 de maio de 2003.
