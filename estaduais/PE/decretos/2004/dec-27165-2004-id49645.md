# Decreto do Executivo n° 27.165

**DECRETO 27.165, DE 23 DE SETEMBRO DE 2004.**

Abre ao Orçamento Fiscal do Estado, relativo ao exercício de 2004, crédito suplementar no valor de R$ 300.000,00, em favor dos Encargos Gerais do Estado.

O GOVERNADOR DO ESTADO, no uso das atribuições que lhe são conferidas pelo inciso IV do artigo 37 da Constituição Estadual, tendo em vista o disposto no inciso IV, do artigo 10, da Lei nº 12.474, de 01 de dezembro de 2003, e considerando a necessidade de reforçar dotação orçamentária insuficiente para cobrir despesas de encargos com restituições e indenizações, não implicando acréscimo ao Orçamento vigente, uma vez que os recursos serão deduzidos de dotação disponível,

DECRETA:

**Art. 1º** Fica aberto ao Orçamento Fiscal do Estado, relativo ao exercício de 2004, em favor dos ENCARGOS GERAIS DO ESTADO, crédito suplementar no valor de R$ 300.000,00 (trezentos mil reais), destinado ao reforço da dotação orçamentária a seguir discriminada:

RECURSOS DO TESOURO EM R$ 1,00

|  | 29000 | - | ENCARGOS GERAIS DO ESTADO |  |
| --- | --- | --- | --- | --- |
|  | 29030 | - | Recursos sob Supervisão da Secretaria da Fazenda - Administração Direta |  |
| Op. Especial: | 29030.288460197.0778 | - | Encargos com Restituições e Indenizações | **300.000** |
|  | 3.3.90 - FNT 0101 | - | Outras Despesas Correntes | 300.000 |
|  |  |  |  | ----------- |
|  |  |  | **TOTAL** | **300.000** |
|  |  |  |  | ======= |

**Art. 2º** Os recursos necessários ao atendimento da despesa de que trata o artigo anterior são os provenientes da anulação, em igual importância, da dotação a seguir discriminada:

| Atividade: | 29030.041230197.0151 | - | Serviços Financeiros | **300.000** |
|  | 3.3.90 - FNT 0101 | - | Outras Despesas Correntes | 300.000 |
|  |  |  |  | ----------- |
|  |  |  | **TOTAL** | **300.000** |
|  |  |  |  | ======= |

**Art. 3º** Este Decreto entra em vigor na data de sua publicação.

**Art. 4º** Revogam-se as disposições em contrário.

Palácio do Campo das Princesas, em 23 de setembro de 2004.
