# Lei Ordinária nº 2.519, de 14 de setembro de 1994

Dispõe sobre autorização ao Prefeito Municipal para alterar nome de ruas de Bairros de Dracena e dá outras providências.

JOSÉ GARCIA MARTINS, Prefeito Municipal de Dracena, Estado de São Paulo, usando das atribuições que lhe são conferidas por lei,

FAZ SABER QUE A CÂMARA MUNICIPAL APROVOU E ELE SANCIONA E PROMULGA A SEGUINTE LEI:

**Artigo 1º** - Fica o Prefeito Municipal autorizado a alterar a denominação das Ruas dos Bairros Jardim Brasilândia, Núcleo Habitacional João Vendramini, Jardim Cristina, Jardim Primavera e Parque do Bosque, localizados em Dracena, conforme seguem:

a) JARDIM BRASILÂNDIA:

Rua A, para Rua Aluísio Azevedo Rua B, para Rua Vinicius de Moraes Rua C, para Rua Manuel Bandeira Rua D, para Rua Machado de Assis Rua E, para Rua Érico Veríssimo Rua F, para Rua Fagundes Varela Rua G, para Rua Aécio de Féo Flora Rua H, para Rua Afonso Arinos Rua I, para Rua Guimarães Rosa Rua J, para Rua Oswaldo Paulino dos Santos Rua K, para Rua Casimiro de Abreu Rua L, para Rua Lima Barreto Rua M, para Rua Padre José de Anchieta Rua N, para Rua Nelson Rodrigues Rua O, para Rua Otto Lara Resende Rua P, para Rua Pero Vaz de Caminha Rua Q, para Rua Mario Quintana Rua R, para Rua Carlos Drumond de Andrade Rua S, para Rua Graciliano Ramos

b) CONJUNTO HABITACIONAL JOÃO VENDRAMINI:

Rua 1, para Rua Monteiro Lobato Rua 2, para Rua Manoel Antonio de Almeida Rua 3, para Rua Cecília Meireles Rua 4, para Rua Carlos Castelo Branco

- Fls. 02 -

c) JARDIM PRIMAVERA:

Rua 1, para Rua Oswaldo Paulino dos Santos Rua 2, para Rua Prof. Leônidas Ramos de Oliveira Rua 3, para Rua Janete Clair

d) JARDIM CRISTINA:

Rua A, para Rua Cora Coralina Rua B, para Rua Graça Aranha Rua C, para Rua Cecília Meireles

e) PARQUE DO BOSQUE:

O prolongamento da Rua C, para Rua Manuel Bandeira O prolongamento da Rua D, para Rua Machado de Assis O prolongamento da Rua 3, para Rua Cecília Meireles

**Artigo 2º** - Esta Lei entrará em vigor na data de sua publicação, revogadas as disposições em contrário.

Gabinete do Prefeito Municipal Dracena, 14 de setembro de 1.994

JOSÉ GARCIA MARTINS Prefeito Municipal

Registrada e publicada por afixação, no lugar público do costume desta Prefeitura e na imprensa local. Dracena, data supra.

DIÓGENES GONÇALVES DE CARVALHO Secretário de Administração CM n.º 61/94
