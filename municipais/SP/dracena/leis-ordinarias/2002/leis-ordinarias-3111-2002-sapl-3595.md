# Lei Ordinária nº 3.111, de 11 de outubro de 2002

(Projeto de Lei nº 080/02, de autoria do Vereador Francisco Eduardo Aniceto Rossi, subscrito pelo Vereador Ivo Figueiredo dos Santos) Dispõe sobre alteração de nome de ruas e denominar praças do Conjunto Habitacional “Emilio Zanatta” e dá outras providências.

ÉLZIO STELATO JUNIOR, Prefeito Municipal de Dracena, Estado de São Paulo, usando das atribuições que lhe são conferidas por lei,

FAZ SABER QUE A CÂMARA MUNICIPAL APROVOU E ELE SANCIONA E PROMULGA A SEGUINTE LEI:

**Artigo 1º** - As ruas do Conjunto Habitacional “Emilio Zanatta”, passam a ser denominadas da seguinte forma:

- Rua 1, para Rua José Xavier Alves - Rua 2, para Rua Tangará da Serra - Rua 3, para Rua Xororó - Rua 4, para Rua Araponga - Rua 5, para Rua Maracanã - Rua 6, para Rua Falcão Peregrino - Rua 7, para Rua Maria Aparecida Bárbara Dutra - Rua 8, para Rua Quintiliano Alves de Oliveira - Rua 9, para Rua dos Beija-Flores - Rua 11, para Rua Águia Dourada - Rua 12, para Rua Canário do Reino - Rua 13, para Rua das Garças - Rua 15, para Rua João-de-Barro - Rua A, para Rua Cezarino Scaliante - Rua B, para Rua Jandaia - Rua C, para Rua Colibri - Rua D, para Rua Rouxinol - Rua E, para Rua dos Cisnes - Rua F, para Rua Flamingo - Rua G, para Rua Juriti - Rua H, para Rua Uirapuru - Rua I, para Rua das Andorinhas - Rua J, para Rua das Marrecas - Rua K, para Rua Sabiá Laranjeira - Rua L, para Rua dos Pardais - Rua M, para Rua Curió - Rua N, para Rua das Gaivotas - Rua O, para Rua dos Condores - Rua P, para Rua Manoel de Carvalho

= fl. 02 =

- Rua Q, para Rua José Avelino de Oliveira - Rua R, para Rua Palmira Reigota Stelatto (com redação modificada pela Emenda Modificativa nº 01/2002, de 16.9.2002)

**Artigo 2º** - A praça da rua 1, do Conjunto Habitacional “Emilio Zanatta passa ser denominado Praça Remo Lorençon.

**Artigo 3º** - A praça da rua C, do Conjunto Habitacional “Emilio Zanatta”, passa a ser denominada Praça Maria Thereza Zanatta. (com redação modificada pela Emenda Modificativa nº 01/2002, de 16.9.2002)

**Artigo 4º** - Esta Lei entra em vigor na data sua publicação, revogadas as disposições em contrário.

Gabinete do Prefeito Municipal Dracena, 11 de outubro de 2.002.

ÉLZIO STELATO JUNIOR Prefeito Municipal

Registrada e publicada por afixação no lugar público do costume desta Prefeitura e na imprensa local.

Dracena, data supra.

DOUGLAS MANFRÉ Secretário de Administração e Governo
