# PORTARIA nº 8/2018 - CPDP

Comissão de Proteção dos Dados Pessoais

PORTARIA nº 8/2018 - CPDP

A Comissão de Proteção dos Dados Pessoais, no uso de suas atribuições legais conferidas pela Lei Complementar nº 75/93, resolve:

Instaurar o Inquérito Civil Público, registrado no SISPROWEB sob o nº 08190.141105/18-13, para investigar a disponibilização, pelo site "Tudo sobre todos", dos dados pessoais dos brasileiros e apurar eventuais responsabilidades.

Brasília-DF, 22 de junho de 2018.

FREDERICO MEINBERG CEROY

Promotor de Justiça
